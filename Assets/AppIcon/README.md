# Automation Health App Icon

This directory contains the source art and generated macOS icon assets for Automation Health.

## ChatGPT Image Prompt

```text
Create 4 polished macOS app icon variants for an app called Automation Health.

The icon concept is "Pulse Grid": a restrained native macOS utility icon that communicates scheduled automations plus health/status at a glance without looking like a dashboard or glossy calendar illustration. Use an off-white or very light gray rounded-square app icon tile with a centered black/graphite abstract glyph. The glyph should combine a compact schedule/grid hint with one pulse-like zigzag stroke, reduced to a simple logo-style mark.

Color direction: mostly monochrome, black/graphite on off-white, with only subtle material depth and a soft macOS shadow. The icon should feel calm, local, technical, and trustworthy, like a tasteful SwiftUI utility sitting beside simple Dock icons. Make the variants differ only in small glyph composition and tile material details.

Important constraints: no text, no letters, no app initials, no date numbers, no logos, no screenshots, no terminal output, no private data, no tiny job rows, no connected-node diagrams, no checkmark badge, no clutter, no bright neon color, no high-gloss decorative finish, no chunky 3D calendar object. The winning variant must stay legible at small Dock and Finder sizes.

Output a square app-icon style image suitable as 1024x1024 source art.
```

## Prompt Rationale

The Pulse Grid metaphor maps scheduled automations to compact grid blocks and health to one pulse-like stroke. The mostly monochrome treatment keeps the icon closer to restrained Dock icons and avoids the glossy, bulky calendar-object look that did not fit the app.
