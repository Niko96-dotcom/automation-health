# Starter ChatGPT Image Prompt: Automation Health Icon

Use this prompt in the ChatGPT app image generator for the first app icon concept.

```text
Create a polished macOS app icon for an app named Automation Health.

Purpose: a local Mac utility that inspects scheduled automations, background jobs, scripts, and their health without modifying them.

Visual concept: a dark graphite rounded-square macOS-style icon with a subtle glassy depth. In the center, show a clean automation/network symbol: three small connected nodes arranged like a scheduler graph, combined with a calm health pulse line or status check motif. The icon should communicate "automation inventory" and "healthy system status" at a glance.

Style: premium native macOS app icon, dimensional but restrained, crisp edges, soft lighting, subtle shadows, no cartoon style, no mascot, no busy background.

Color palette: charcoal, deep graphite, muted blue accent, small green healthy-status accent. Avoid purple-dominant gradients, neon cyberpunk, orange/brown palettes, and generic stock-tech imagery.

Composition: centered symbol, strong silhouette, readable at small sizes, enough padding for macOS rounded-corner masking. No text, no letters, no numbers, no logos, no watermark.

Output: square 1024 x 1024 image, high detail, suitable as source art for generating a macOS .icns app icon.
```

Optional alternate direction:

```text
Create a second refined macOS app icon concept for Automation Health using the same constraints, but make the central symbol look like a compact sidebar/list with health dots connected to a subtle clock/schedule ring. Keep it native, elegant, minimal, and readable at small icon sizes. No text, no logos, no watermark.
```
