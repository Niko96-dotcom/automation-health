## Resolved Audit Gap

### QUAL-04: The local CI gate builds successfully after the sidebar changes

The first audit run found that `./script/ci.sh` failed because `JobHumanizer.relativeRunDescription(for:relativeTo:)` used real-current-date helpers for today/tomorrow/yesterday instead of the supplied `relativeTo` date. The production helper was updated to compute day offsets from the provided reference date.

Verification after the fix:

- `swift run ActiveJobsCoreSelfTest` passed.
- `./script/ci.sh` passed.
