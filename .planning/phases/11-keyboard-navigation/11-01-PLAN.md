**1. Add AppKit import and NSSearchField focus helper (per D-05/D-11)**

Add `import AppKit` at the top of the file (ContentView already has `import SwiftUI` and `import ActiveJobsCore`; AppKit is needed for `NSApp`, `NSToolbar`, `NSSearchField`).

Add a private method to ContentView:
```swift
private func focusSearchField() {
    guard let window = NSApp.keyWindow,
          let toolbar = window.toolbar else { return }
    for item in toolbar.visibleItems ?? [] {
        if let searchField = item.view as? NSSearchField {
            window.makeFirstResponder(searchField)
            return
        }
    }
}
```

This iterates the toolbar's visible NSToolbarItem views to find the NSSearchField that `.searchable` places there. When found, it makes it first responder, focusing the field.

**2. Add .onChange to observe requestSearchFieldFocus flag (per D-05)**

Add the following modifier to the `NavigationSplitView` (after `.navigationSplitViewColumnWidth`):
```swift
.onChange(of: preferences.requestSearchFieldFocus) { _, shouldFocus in
    if shouldFocus {
        focusSearchField()
        preferences.requestSearchFieldFocus = false
    }
}
```

This fires when Cmd+Shift+F is pressed (Task 2 sets the flag). It focuses the NSSearchField via AppKit, then immediately resets the flag so subsequent changes don't re-trigger.

**3. Add Escape key handler (per D-11)**

Add the following modifier to the `NavigationSplitView` (after the `.onChange` above):
```swift
.onKeyPress(.escape) {
    if !searchText.isEmpty || NSEvent.modifierFlags.isEmpty {
        searchText = ""
        preferences.requestJobListFocus = true
        return .handled
    }
    return .ignored
}
```

When Escape is pressed:
- If `searchText` is non-empty → clear it AND signal job list to take focus
- If `searchText` is already empty but the search field might be focused → still signal job list focus (via `requestJobListFocus`)
- The `NSEvent.modifierFlags.isEmpty` guard ensures Escape-with-modifier (e.g., Option+Escape) passes through
- Returns `.handled` when action is taken, `.ignored` otherwise so system Escape behavior (e.g., dismissing sheets) still works
