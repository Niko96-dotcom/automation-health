# Phase 05 - UI Design Contract

> Visual and interaction contract for Phase 5. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Boundary

Phase 5 creates the app's icon identity and deterministic local icon asset pipeline. It does not redesign the app shell, add public screenshots, add a marketing hero, require paid API generation, sign/notarize the app, or change scanner behavior.

Locked decisions from `05-CONTEXT.md`:

- Primary metaphor: Pulse Calendar.
- Anchor shape: calendar tile with one green pulse line.
- Automation detail: subtle calendar grid or timing marks only.
- Style: native macOS utility, cool graphite plus green, soft 3D depth.
- Text: no letters, initials, dates, calendar numbers, or other writing inside the icon.
- Workflow: one copy-paste-ready ChatGPT prompt that asks for 4 variants; selected source PNG is committed as the stable source art.
- Documentation posture: manual ChatGPT generation is the expected path; paid API or CLI generation must not be required.

## Typography

Use exactly these type roles for any Phase 5 documentation snippets, generated preview labels, or verification output. The icon artwork itself must contain no text.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 600 | 1.3 |
| Body | 14px | 400 | 1.5 |
| Heading | 18px | 600 | 1.25 |

Typography constraints:

- Allowed weights: 400 regular and 600 semibold only.
- Use monospaced system text only for command snippets and file paths.
- Do not add decorative type, lettering, initials, or calendar numbers to the generated icon prompt.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#2B3036` | Graphite rounded-square icon body, primary utility surface |
| Secondary (30%) | `#56616D` | Raised calendar tile, beveled edges, subtle schedule marks |
| Accent (10%) | `#32D583` | Health pulse line, restrained pulse glow, selected-variant callout |
| Destructive | `#D92D20` | Destructive warnings only; no destructive action is introduced in this phase |

Accent reserved for: the pulse line, a very small pulse glow/reflection, and selected-variant documentation callouts. Do not use the green accent as the default color for every control, broad backgrounds, app-wide tint replacement, or decorative fills.

Visual hierarchy:

- Primary focal point: the green pulse line crossing the calendar tile.
- Secondary focal point: the rounded graphite calendar tile with soft dimensional depth.
- Tertiary details: subtle grid/timing marks that remain legible at small sizes.
- Avoid miniature sidebar rows, connected-node diagrams, screenshots, terminal text, logs, personal paths, and clutter.

## Icon Composition Contract

The generated source art must read as a macOS app icon at 16px, 32px, 128px, and 1024px.

| Element | Contract |
|---------|----------|
| Canvas | Square app-icon composition, suitable for 1024x1024 source art |
| Base shape | Rounded graphite macOS-style tile with soft depth |
| Main object | Calendar tile or calendar face, centered and instantly recognizable |
| Health signal | One green pulse line across or over the calendar tile |
| Schedule cues | Minimal grid/timing marks; low contrast; no numbers |
| Lighting | Gentle highlight and shadow, restrained native utility finish |
| Detail density | Low enough to survive small icon sizes |
| Forbidden content | Text, letters, initials, date numbers, logos, screenshots, terminal output, private data, job rows, graph nodes, excessive badges |

Accessibility and legibility:

- The pulse line must have enough contrast against the graphite/calendar surface to remain visible in the Dock and Finder.
- The silhouette must remain recognizable in grayscale or low-saturation previews.
- No meaning may depend on tiny internal details.

## Copy-Paste ChatGPT Image Prompt

Use this as the Phase 5 source-art prompt:

```text
Create 4 polished macOS app icon variants for an app called Automation Health.

The icon concept is "Pulse Calendar": a native macOS utility icon that communicates scheduled automations plus health/status at a glance. Use a rounded graphite app-icon tile with soft 3D depth, gentle highlights, and restrained shadows. The central recognizable shape should be a clean calendar tile or calendar face, with subtle schedule cues such as a minimal grid or timing marks. Add one clear green health pulse line across or over the calendar tile as the main accent.

Color direction: cool graphite neutral base with a vivid but restrained green health accent. The icon should feel calm, local, technical, and trustworthy, like a native SwiftUI macOS utility. Make the variants differ only in small composition/material details, such as pulse placement, depth, lighting, and calendar surface treatment.

Important constraints: no text, no letters, no app initials, no date numbers, no logos, no screenshots, no terminal output, no private data, no tiny job rows, no connected-node diagrams, no checkmark badge, no clutter, no high-gloss decorative finish. The winning variant must stay legible at small Dock and Finder sizes.

Output a square app-icon style image suitable as 1024x1024 source art.
```

Selection notes must record:

- Which of the 4 variants was chosen.
- Why it remains legible at small sizes.
- Why it preserves the Pulse Calendar metaphor.
- Confirmation that it contains no text, private data, screenshots, local paths, terminal output, or real scheduler details.

## Asset Pipeline Contract

| Artifact | Contract |
|----------|----------|
| Source PNG | Commit the selected original source image at `Assets/AppIcon/automation-health-icon-source.png` |
| Generated iconset | Generate deterministic app icon files under `Assets/AppIcon/AutomationHealth.iconset/` |
| Generated `.icns` | Generate `Assets/AppIcon/AutomationHealth.icns` from the iconset |
| Script | Add a local deterministic script named `script/generate_app_icon.sh` |
| Bundle integration | `script/build_and_run.sh` must copy `AutomationHealth.icns` into `Contents/Resources` and set `CFBundleIconFile` |
| Documentation | Add concise regeneration notes to `docs/development.md`; README may link or mention the icon workflow briefly |

Implementation constraints:

- Use built-in macOS tooling such as `sips` and `iconutil` unless a later plan proves a dependency is necessary.
- The generation path must run from the repository root and require no secrets or network access.
- Generated outputs in `dist/` remain uncommitted.
- The committed source PNG and generated `.icns` must be privacy-safe public assets.
- Verification should include checking the `.app` bundle contains `Contents/Resources/AutomationHealth.icns` and an `Info.plist` icon key.

## Interaction Contract

Phase 5 adds no new in-app control surface. Any command, script, or documentation affordance introduced by this phase must use explicit text labels.

| Interaction | Contract |
|-------------|----------|
| Regenerate assets | Command label: `Generate Icon Assets`; shell command: `./script/generate_app_icon.sh` |
| Verify bundle icon | Command label: `Verify App Icon`; existing `./script/build_and_run.sh --verify` remains the app launch check |
| Select variant | Manual maintainer action recorded in short selection notes |
| Reveal/generated files | File paths are written as text paths in docs, not hidden behind icon-only controls |
| Destructive actions | None |

No icon-only actions are introduced. If a future toolbar or Finder reveal affordance is touched while integrating the icon, it must retain a text label, help text, or accessibility label.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Generate Icon Assets |
| Empty state heading | Icon source art needed |
| Empty state body | Choose one ChatGPT variant and place the selected PNG at `Assets/AppIcon/automation-health-icon-source.png`. |
| Error state | Icon asset generation failed. Confirm the source PNG exists, then rerun `./script/generate_app_icon.sh` from the repository root. |
| Destructive confirmation | None - this phase does not add destructive actions. |

Copy tone:

- Plain, local, and practical.
- Do not imply upload, analytics, cloud sync, signing, notarization, or paid API generation.
- Do not include real scheduler output, job names, usernames, hostnames, local personal paths, screenshots, or terminal output in public docs or assets.
