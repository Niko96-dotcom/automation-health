<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ChatGPT generated image -> public repository asset | Generated image output could accidentally include fake text, logos, screenshots, terminal output, job details, paths, or private-looking data. |
| Maintainer manual selection -> committed source art | The chosen variant becomes the source of truth for all generated bundle icons. |
| Public docs -> future regeneration workflow | Documentation must not imply API keys, paid generation, or upload of private scheduler data is required. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Information Disclosure | Generated source PNG | mitigate | Prompt and selection notes explicitly reject text, screenshots, terminal output, local paths, private data, and real scheduler details. |
| T-05-01-02 | Spoofing | App icon metaphor | mitigate | Require calendar tile plus one green pulse line; reject unrelated dashboards, graphs, logos, and clock-only symbols. |
| T-05-01-03 | Repudiation | Manual image selection | mitigate | Record selected variant, small-size legibility, metaphor check, and privacy check in `Assets/AppIcon/README.md`. |
| T-05-01-04 | Elevation of Privilege | Image generation workflow | avoid | Do not require API keys, CLI generators, secrets, or automated network image generation. |
</threat_model>
