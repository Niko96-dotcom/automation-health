<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scanner/domain records -> presentation grouping | Local scheduler data is treated as display input only; grouping must not mutate records or read source files. |
| Presentation helpers -> SwiftUI views | Views consume prepared values and should not reintroduce scanner/file/process IO. |
| Hidden rows -> selection/navigation | Collapse/search visibility must not silently select a different automation record. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | Sidebar presentation | avoid | Plan 08-01 changes no scanner mutation paths and adds no edit/run/delete behavior for real automation files. |
| T-08-02 | Information Disclosure | Presentation target | mitigate | Grep verifies `AutomationHealthCore` contains no `Data(contentsOf:)`, `FileManager.default`, process calls, `launchctl`, `crontab`, or `shortcuts list`. |
| T-08-03 | Spoofing | Trigger classification | mitigate | Tests verify registered/candidate/manual records keep conservative evidence labels and are not described as scheduled without direct evidence. |
| T-08-04 | Repudiation | Hidden selection | mitigate | Navigation helpers preserve selected ID context and tests cover movement from hidden selected rows. |
| T-08-05 | Denial of Service | Grouping helpers | mitigate | Helpers group existing in-memory arrays only and use deterministic order arrays; no filesystem traversal or unbounded IO is added. |
| T-08-06 | Information Disclosure | Preference state | avoid | Collapse/grouping state remains in-memory value state and is not persisted in this plan. |
</threat_model>
