# Support

Automation Health is a local, best-effort inspection tool for scheduled jobs. Support is focused on the app, scanner behavior, documentation, and contributor workflow.

## Where To Ask

- Use the bug report issue form for reproducible app, scanner, build, or documentation problems.
- Use the feature request issue form for new scanner sources, UI ideas, or workflow improvements.
- Use security reporting guidance in `SECURITY.md` for security or privacy concerns.

## Keep Reports Privacy-Safe

Please do not paste raw logs, screenshots, scheduler output, local paths, hostnames, job names, tokens, secrets, or private command output into public issues. Share sanitized summaries or synthetic examples instead.

Support cannot diagnose private local automations from raw output. If a report needs local data to be understandable, replace sensitive values with placeholders before posting.

## Response Expectations

This project does not promise 24/7 support or guaranteed response times. Maintainers and contributors will triage reports as availability allows.
